📖 使用说明 · 喝水提醒

三步上车,从此告别下午 4 点头疼。

① 装上插件
  1. 点 下载 按钮去 Chrome 商店,或本地 chrome://extensions 加载已解压版本。
  2. 装完会看到右上角多了一个 💧 图标。
② 配置提醒
  1. 点 💧 图标 → 进入设置面板(就是上一个弹窗那个)。
  2. 设置 提醒间隔 / 每次毫升 / 每日目标。
  3. 把 免打扰时段 设成你睡觉的时间,半夜不会被吵。
③ 开始喝
  • 到点会有桌面通知 叮~ 喝水啦。
  • 点通知里的 我喝了 累计今日水量;点 稍后提醒 顺延 5 分钟。
  • 会议中?按 ⌘ Shift H 一键静默 1 小时。
常见问题
  • 不弹通知? 系统设置 → 通知 → 给 Chrome 打开权限。
  • 数据存哪儿? 全部在浏览器本地,不上传任何服务器。

📖 使用说明 · 标签收纳

第一次用先填 API key,之后就是一键的事。

① 填 LLM Key
  1. 点扩展图标 → 设置 → API Key。
  2. 支持:OpenAI / Anthropic / DeepSeek / 月之暗面 / 智谱。
  3. Key 只存浏览器本地,不上报任何地方。
② 一键归档
  1. 50 个标签开累了 → 按 ⌘ Shift S(或点工具栏图标)。
  2. AI 会用每个标签的标题 + URL 给你分组,常见组:工作 / 学习 / 购物 / 摸鱼 / 待读。
  3. 不满意?直接拖到别的组,下次它会记住你的偏好。
③ 一键恢复
  • 侧边栏选一个组 → 恢复全部 或 挑几个恢复。
  • 找东西用顶部搜索框,模糊搜标题/URL/分组都行。
隐私
  • 归档的标签信息只发给 你自己 的 LLM endpoint,不经过我的服务器。
  • 所有数据 = 浏览器本地 IndexedDB,卸载即清空。
